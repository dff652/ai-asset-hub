### 5.2 已知 P1：推荐升级命令缺少显式版本

`v0.1.4` 和 `v0.1.5` 的 `aiah update --check` 会输出：

```bash
curl -fsSL https://raw.githubusercontent.com/dff652/ai-asset-hub/v0.1.5/scripts/install.sh | sh
```

但 `v0.1.5` tag 内安装器按当时的 staged-pin 规则仍默认 `v0.1.4`。隔离复现确认：
v0.1.4 用户执行该推荐命令后仍停留在 v0.1.4。正确的临时命令是：

```bash
curl -fsSL https://raw.githubusercontent.com/dff652/ai-asset-hub/v0.1.5/scripts/install.sh |
  AIAH_VERSION=0.1.5 sh
```

显式版本命令已完成真实升级验证；[v0.1.5 Release](https://github.com/dff652/ai-asset-hub/releases/tag/v0.1.5)
说明已添加 Known issue。tag 和产物不重写。后续必须修复生成命令并调整 release
runbook/test，使验收执行**程序实际输出的命令**，不能只验证手工补齐版本的等价命令。

因此 v0.1.5 的准确状态是：**发布产物、显式版本升级和核心 TUI 行为已验收；推荐升级
命令未验收通过。** 安装器默认 pin 与用户文档的最终收口必须和该 P0 修复一起处理。
